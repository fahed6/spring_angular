────────────────────────────────────────────────────────────────────────────────
  TC-SWG-03 : Connexion via Swagger — obtenir un token JWT
────────────────────────────────────────────────────────────────────────────────
  Prérequis  : TC-SWG-01 réussi

  Étapes :
    1. Dans Swagger UI, dérouler "Authentification"
    2. Cliquer sur "POST /api/auth/login"
    3. Cliquer "Try it out"
    4. Saisir dans le corps :
         {
           "email": "admin@autoecole.com",
           "password": "admin123"
         }
    5. Cliquer "Execute"

  Résultat attendu :
    - Code réponse : 200
    - Corps de la réponse :
        {
          "token": "<chaîne JWT longue>",
          "role": "ADMIN",
          "fullName": "Admin"
        }
    - Le token commence par "eyJ" (encodage base64 d'un JWT)

────────────────────────────────────────────────────────────────────────────────
  TC-SWG-04 : Autoriser Swagger avec le token JWT (Authorize)
────────────────────────────────────────────────────────────────────────────────
  Prérequis  : TC-SWG-03 réussi, token copié

  Étapes :
    1. Copier la valeur du champ "token" (sans guillemets)
    2. Cliquer le bouton "Authorize" (cadenas) en haut de la page
    3. Dans le champ "bearerAuth (http, Bearer)", coller :
         Bearer <token_copié>
    4. Cliquer "Authorize" puis "Close"

  Résultat attendu :
    - Le cadenas passe à l'état "fermé" (verrouillé)
    - Tous les endpoints sont maintenant autorisés pour l'exécution

================================================================================
  QUESTIONS PROBABLES DU PROFESSEUR
================================================================================

  Q: Pourquoi Swagger est-il accessible sans token ?
  R: La page Swagger UI (/swagger-ui.html) et la spec JSON (/api-docs) sont
     déclarées en permitAll() dans SecurityConfig car ce sont des ressources
     de documentation. Les endpoints API eux-mêmes restent protégés.

  Q: Comment le token JWT est-il transmis dans Swagger ?
  R: Via le bouton "Authorize" — on saisit "Bearer {token}". Swagger ajoute
     automatiquement le header "Authorization: Bearer {token}" à chaque requête.

  Q: Quelle est la différence entre 401 et 403 ?
  R: 401 Unauthorized = pas authentifié (pas de token ou token invalide).
     403 Forbidden = authentifié mais pas autorisé (ex: staff sur /api/admin).

  Q: Comment les erreurs de validation sont-elles structurées ?
  R: Grâce à @Valid sur les paramètres des contrôleurs et @RestControllerAdvice.
     Le GlobalExceptionHandler intercepte MethodArgumentNotValidException et
     retourne un ErrorBody avec le code VALIDATION_ERROR + la map des champs.

  Q: Quelles sont les annotations OpenAPI utilisées ?
  R: @Tag (groupe un contrôleur), @Operation (décrit un endpoint),
     @ApiResponse (documente un code retour), @Parameter (décrit un paramètre),
     @Schema (documente un champ de DTO), @SecurityRequirement (sécurité JWT).
